# Period Planner

A single-page homework planner with a tab for each of 8 class periods. Add assignments, set due dates, check them off.

Everything is in `index.html`. No build step.

## Put it online with GitHub Pages

1. Create a new repository on GitHub and upload `index.html` and this README.
2. Open the repository's **Settings > Pages**.
3. Under **Build and deployment**, pick **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. After a minute the site is live at `https://<your-username>.github.io/<repository-name>/`.

## Where homework is saved

On GitHub Pages the planner saves in the browser you use, on that device only. It does not have user accounts. Accounts need a server to store logins and homework, such as Supabase or Firebase.
